# S5Max Edge 配音与纯净画面设计

## 目标

将两条 S5Max 示范片的 macOS `Tingting` 配音替换为 Microsoft Edge 中文神经男声 `zh-CN-YunxiNeural`，并移除模板生成的全部角落品牌、SKU 和 CTA 角标，只保留正文字幕。

## 实现

- 使用 `uvx --from edge-tts edge-tts` 7.2.8 在线生成语音，不向仓库增加 Python 依赖。
- 六句文案分别生成，再按现有六段镜头时长做最小速度调整或尾部补静音，保持字幕与镜头结构不变。
- `ProductMarketingChrome` 只渲染 `SubtitleLayer`；素材画面中的实体产品 Logo 不处理。
- 输出覆盖两条老板验收版，静音基底保留，方便再次更换声音。
- Edge 服务拒绝第一条中的原充电句；实际口播归一化为“接口快充，大容量电池长续航，出门旅行更放心”，画面字幕保持原销售文案。

## 验收

- 两条成片均为 1080×1920、30fps、H.264/AAC，时长和帧数不变。
- 四角没有模板品牌、SKU 或 CTA 字样，正文字幕仍存在。
- CTA 末帧仍保留产品；完整解码无错误。

## 范围限制

Edge TTS 使用微软在线服务，适合本次快速试样；正式批量生产前再评估 Azure Speech 的服务条款和稳定性。
