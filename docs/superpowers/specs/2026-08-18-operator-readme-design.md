# 操作员 README 设计

## 目标

在根目录提供一份面向日常视频生产操作员的 `README.md`。操作员只需准备原始文案，即可理解并执行本地单条或批量生产；无需阅读实现代码、历史设计文档或手工编写 ProductionPlan/Timeline。

## 内容结构

README 按实际操作顺序组织：

1. 项目用途与硬边界。
2. Node、Python、SMB、IndexTTS 2.5、本地音色和素材的开始前检查。
3. 最短操作路径。
4. `capacity`、`prepare`、`sample`、`approve`、`reject`、`render` 六个公开命令。
5. 单条随机生产示例。
6. 默认 300 条且 meaningful unique 的批量生产示例。
7. 样片审批、拒绝归档和断点恢复。
8. 批次目录、正式输出和必须保留的审计产物。
9. 常见本地故障与处理方法。

## 写作规则

- 命令和参数以当前 `scripts/s5max-daily.py --help` 及各子命令帮助为准。
- 只保留一套公开操作流程，不引入第二套 TTS、Remotion 或编码入口。
- 明确用户只提供原始文案；分类、拆句、组合、计划和时间线由系统内部生成。
- 明确 SMB 必须、本地 IndexTTS 2.5 必须、Remotion 是唯一最终成片路径。
- 不承诺未经真实执行验证的环境路径或模型安装位置；用参数占位符并解释其含义。
- 保留既有 `work/`、`out/` 产物，不指导删除或覆盖历史数据。

## 验收

- 根目录存在 `README.md`。
- README 中六个公开命令与 CLI 帮助一致。
- 单条和批量流程均能从原始文案开始完整走通到交付路径。
- 批量流程明确默认 300、唯一性和首条样片审批门。
- 文档不要求操作员手工提供 ProductionPlan、Timeline 或镜头表。
- Markdown 无占位 TODO，命令示例可通过 `--help` 静态核对。
